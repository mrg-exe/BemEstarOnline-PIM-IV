# Definição de Pronto (DoD) e entregas

## Um item está PRONTO quando
1. O código compila sem erros e está no GitHub.
2. Foi testado manualmente no site/app pelo menos uma vez com o roteiro de demonstração.
3. A API devolve mensagens de erro claras (`{ "mensagem": "..." }`).
4. A tela funciona no celular (responsiva) e com teclado.
5. A documentação do item (README/docs) foi atualizada.
6. O pipeline de CI passou (API compila, scripts SQL rodam, JavaScript sem erro de sintaxe).
